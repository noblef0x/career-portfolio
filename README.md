# Patrick Stralina — Career Portfolio

Static site (index.html, styles.css, script.js) plus resume.pdf.

## Publish on GitHub Pages
1. Create a public repository and upload all five files to the root.
2. Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder: / (root) → Save.
3. After a minute the site is live at https://YOUR-USERNAME.github.io/REPO-NAME/
4. Paste that link into the highlighted spot in the Word resume, then save the Word file as your final upload.

## Before publishing
- Confirm every metric matches your resume.
- Open index.html locally first (or run `python3 -m http.server 8000`).
